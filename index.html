Catch-Up for Confluence

Catch-Up brings Confluence documents and repository updates into one shared, chronological news feed inside Confluence — with discussion beneath each post and a private reading place for every person. Catch up after a week away without digging through spaces.

  • Shared feed, personal state. Everyone sees the same history; seen, saved and reading position stay private to each reader.
  • Confluence sources. Share a published page to the feed once, or let a feed owner track future changes — edits are grouped and published as one tidy update.
  • ADR and Markdown updates from Git. Optional signed publishers for Azure DevOps and GitHub post selected document changes with links back to the repository.
  • Runs entirely on Atlassian Forge. No external servers, no third-party analytics, no AI services. Your data stays in your site's app storage.
